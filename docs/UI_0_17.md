# Corvo Library V2 — UI 0.17

## Direção
Interface dark premium, rápida e operacional, inspirada na referência visual aprovada: menos aparência de CRM e mais sensação de sistema operacional da fábrica Corvo.

## Navegação principal
A sidebar possui apenas seis áreas:

1. Visão geral
2. Assets
3. Projetos
4. Execuções
5. Análise
6. Configurações

As ferramentas existentes continuam disponíveis como abas internas.

### Assets
- Catálogo — somente aprovados
- Pendentes
- Rejeitados

Pendentes e Rejeitados não aparecem mais isolados na sidebar.

### Projetos
- Projetos
- Solicitações
- Lotes
- Importações

### Execuções
- Coleta automática
- Inbox candidatas
- Operação

### Análise
- Estoque & giro
- Políticas

## Visão geral
O dashboard usa dados reais já expostos pelo Core:
- assets aprovados
- agentes/sessões ativos
- projetos em execução
- taxa de sucesso das operações recentes
- D1, R2 e Queue
- heartbeats/sessões
- projetos ativos
- atividade recente

## Assets
- tabs claras para Catálogo/Pendentes/Rejeitados
- seleção múltipla preservada
- ZIP em massa preservado
- aprovação em lote preservada
- exclusão permanente preservada
- reconciliação R2 dentro de Pendentes
- imagens quebradas usam placeholder visual limpo em vez do ícone nativo do navegador

## Responsividade
Desktop mantém sidebar fixa. Em telas menores, a navegação vira uma faixa horizontal compacta e rolável, preservando os seis módulos principais.
