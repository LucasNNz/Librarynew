# Corvo Library V2 — UI 0.18

Checkpoint visual orientado pela referência dark premium fornecida para a Corvo Library.

## Mudanças principais

- sidebar compacta e mais fiel à referência, com ícones vetoriais React consistentes;
- marca Corvo redesenhada em SVG inline, sem dependência externa;
- topo integrado à composição da página, sem barra administrativa pesada;
- título da Visão geral no formato `Visão geral da Corvo Library`, com destaque roxo;
- quatro KPI cards com ícones circulares, glow discreto e dados reais;
- novo componente React `AgentProjectNetwork`, com SVG responsivo e conexões luminosas entre agentes e projetos;
- bloco de agentes ocupa toda a largura útil e funciona como elemento principal do dashboard;
- projetos em execução apresentados em faixa horizontal;
- atividade recente condensada em barra horizontal;
- D1, R2, Queue e heartbeat continuam representados por dados reais, sem criar um backend visual paralelo;
- Assets permanece consolidado em Catálogo / Pendentes / Rejeitados;
- nenhum dado fictício é criado: quando não existem projetos, aparecem slots livres visualmente neutros.

## Técnica

O painel de agentes usa SVG desenhado em React, com curvas, nós e glow. Os cards e ícones usam componentes inline, evitando dependência adicional de biblioteca de ícones no runtime.

## Princípio

A interface deve parecer um cockpit operacional da fábrica Corvo, não um CRM. Beleza visual não pode esconder nem substituir ações reais do Core.
