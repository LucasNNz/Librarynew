# 0.20.26 — Projects Visual Studio

Atualização exclusivamente visual/operacional da aba Projetos, mantendo o Core 0.20.25 e schema 2.19.0.

## Entregue

- KPIs no topo com dados reais de projetos.
- Busca compacta e ação Novo projeto.
- Lista lateral ampla e navegável, com cards, lifecycle, progresso e estado de agente.
- Detalhe principal inspirado na referência visual fornecida.
- Pipeline visual de Roteiro, Referência, Coletor, Analista visual e Baixador.
- Cards de slots integrados com progresso real.
- Agentes ativos exibem owner, execution ID, heartbeat e expiração do lease.
- Resumo do projeto usa contadores reais de cenas, alvo, MATERIALIZED, aprovados, falhas, thumbs e títulos.
- Sinais recentes derivados de workflow tags/slots, sem dados fictícios.
- Ações em massa e bloqueio MCP de projetos fechados preservados.

- Core: 0.20.25

- Migration nova: nenhuma
